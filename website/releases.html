Independent verification

Verify before installing

Do not trust a checksum copied from the page alone. Check out the exact release tag, pin the public key from that source revision, and verify the detached signature over the exact JSON bytes before trusting its fields.

  1. Download the metadata.Save releases.json and releases.json.sig without editing either file.
  2. Pin the public key.Use website/qspline-release-ed25519.pub from the tagged source revision. The release page exposes that file only after the first signed candidate publishes it.
  3. Run the verifier.From the same tagged checkout, select the platform, architecture, and package format you downloaded.
python3 scripts/release.py verify \
  website/_data/releases.json website/_data/releases.json.sig \
  --public-key-file website/qspline-release-ed25519.pub \
  --platform PLATFORM --architecture ARCH --format FORMAT \
  --artifact DOWNLOADED_PACKAGE

The verifier uses Ed25519 for the detached manifest signature, then checks the package byte count and SHA-256 digest. It does not fetch or install software.

Project policy

Privacy and source

This static website has no analytics, account system, advertising, tracking pixels, or telemetry. It fetches the checked-in release index from the same origin. Download links point to unauthenticated HTTPS attachments on the authoritative Forgejo release.
