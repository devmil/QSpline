# QSpline brand assets

`qspline-icon.svg` is the editable application-icon source. `generate-icons.sh` creates the
desktop and website PNG, ICO, and ICNS exports from it. `generate-website-feature-graphic.sh`
composes the Open Graph image from the icon, restrained typography, and the abstract commit-lane
background in `qspline-feature-background.svg`. It deliberately does not use a product screenshot.

These QSpline project assets are available under GPL-3.0-or-later with the rest of the repository.
